SmartDesk

SmartDesk is a C++ desktop project developed using Programming Fundamentals and Object-Oriented Programming concepts.

Features

- Simple and user-friendly desktop application
- Uses Object-Oriented Programming concepts
- Uses Programming Fundamentals concepts
- Organized and reusable C++ code
- Designed as a practical project for everyday use

Technologies

- C++
- Programming Fundamentals
- Object-Oriented Programming
- Visual Studio

Project Structure

- "main.cpp" — Main program
- "SmartDesk.slnx" — Visual Studio solution
- "SmartDesk.vcxproj" — Visual Studio project
- ".gitignore" — Files excluded from Git

Purpose

The purpose of SmartDesk is to build a useful C++ application while applying the concepts learned in Programming Fundamentals and Object-Oriented Programming in a practical project.
